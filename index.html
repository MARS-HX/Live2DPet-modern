Offline Voice Input

Hands-free voice input that runs entirely on this machine — no network, no cloud service. The engine (libvosk) and the Chinese model are downloaded once, then recognition is fully offline.

After downloading, enable “hands-free voice input” below and start the pet. Speak normally — recognised speech goes to the pet exactly like a chat message.

Use the pet in OBS

Recommended: add the pet as an OBS Browser Source. OBS draws the pet itself, so transparency works properly and there is no window capture involved at all. Nothing extra appears on your desktop.

Size and position of the pet inside the source

Changes apply to OBS immediately — no need to re-add the source. Negative Y moves the pet up, positive moves it down.

  1. In OBS: Sources → ＋ → Browser.
  2. Paste the URL above, set the size (for example 400 × 600), then OK.
  3. That is it — the pet appears with a real transparent background.

Only if you prefer capturing the window instead

OBS normally reads a black rectangle from this window: Chromium bypasses the Windows GDI. Compatibility mode brings it back onto a capturable path, at the cost of some rendering performance.

Bilibili Live Danmaku

Connect the pet to a live room and let it react to the chat. It reads danmaku over Bilibili's own WebSocket — no login required.

Stored encrypted on this machine only. Leave empty for an anonymous connection. If a room delivers nothing, logging in sometimes helps.
